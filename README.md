# ☕ Java Programming Practice

Welcome to my **Java Programming Practice Repository** 🚀

This repository contains my solutions to various programming problems implemented in **Java**. Each problem is organized into a separate folder with its corresponding Java source file.

The purpose of this repository is to improve my **Java programming, problem-solving, logical thinking, and coding skills** through regular practice.

---

## 📂 Programs

### 1. 🏧 ATM Withdrawal

A Java program that simulates an ATM withdrawal operation and handles the required conditions for a successful withdrawal.

📁 **Folder:** `ATM-Withdrawal`

---

### 2. 🔤 Count Vowels

A Java program to count the number of vowels present in a given string.

📁 **Folder:** `Count-Vowels`

---

### 3. 📊 Find Column-wise Sum

A Java program that calculates the sum of elements in each column of a matrix.

📁 **Folder:** `Find-Column-wise-Sum`

---

### 4. ⚡ Kinetic Energy Computation Module

A Java program that computes the kinetic energy of an object using its mass and velocity.

**Formula:**

```text
Kinetic Energy = ½ × mass × velocity²
```

📁 **Folder:** `Kinetic-Energy-Computation-Module`

---

### 5. 🛣️ Minimum Path Sum

A Java program that finds the minimum possible path sum through a given grid.

📁 **Folder:** `Minimum-Path-Sum`

---

### 6. 🍔 Online Food Order Status Interpreter

A Java program that interprets the status of an online food order and displays the corresponding result.

📁 **Folder:** `Online-Food-Order-Status-Interpreter`

---

### 7. 🔄 Reversing an Array

A Java program that reverses the elements of an array.

📁 **Folder:** `Reversing-an-Array`

---

### 8. 🔀 Zigzag Conversion

A Java program that converts a given string into a zigzag pattern based on the specified number of rows.

📁 **Folder:** `Zigzag-Conversion`
